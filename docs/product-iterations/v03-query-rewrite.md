# v03：Query 重写职责拆分

## 版本目标

解决问题重写后混入用户 ID、当前时间等噪声，导致知识库召回不准的问题。

## 修复前

系统把重写后的问题、用户 ID、当前时间拼成一条 Query，再同时发给向量检索、全文检索和 SQL 检索。

这对 SQL 有帮助，但对知识库检索是噪声，会拉偏 embedding，也会干扰 BM25。

## 修复后

把输入拆成两类：

- 知识库检索只使用干净的问题 Query。
- SQL 检索器内部使用用户 ID、当前时间等业务上下文。

## 产品价值

v02 解决关键词能不能召回，v03 解决 Query 本身是否干净。只有 Query 干净，后面的混合检索才有意义。
